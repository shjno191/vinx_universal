# 詳細設計書：マスタ管理―共通_システムコントロール取得処理

## 1. 目的
本処理は、システム全体の動作を制御するパラメータ（システムコントロール）をデータベースから取得し、アプリケーション内で利用可能にすることを目的とする。

## 2. 処理概要
指定された「コントロールキー」および「セクション」に基づき、システムコントロールマスタ（`M_SYSTEM_CONTROL`）から該当する設定値を取得する。

## 3. インターフェース定義

### 3.1. 入力パラメータ (Input)
| 項目名 | 物理名 | 型 | 必須 | 備考 |
| :--- | :--- | :--- | :--- | :--- |
| コントロールキー | `control_key` | String | ○ | パラメータの一意識別子 |
| セクション | `section` | String | - | パラメータの分類（省略可） |

### 3.2. 出力パラメータ (Output)
| 項目名 | 物理名 | 型 | 備考 |
| :--- | :--- | :--- | :--- |
| コントロール値 | `control_value` | String | 取得された設定値（未取得時はnullまたはデフォルト値） |

## 4. テーブル定義 (参照)

### 4.1. システムコントロールマスタ (`M_SYSTEM_CONTROL`)
| 物理名 | 論理名 | 型 | PK | 備考 |
| :--- | :--- | :--- | :--- | :--- |
| `CONTROL_KEY` | コントロールキー | VARCHAR(50) | ○ | |
| `SECTION` | セクション | VARCHAR(50) | ○ | デフォルトは'COMMON' |
| `CONTROL_VALUE` | コントロール値 | TEXT | | |
| `DESCRIPTION` | 説明 | VARCHAR(255) | | パラメータの用途説明 |

## 5. 詳細ロジック

### 5.1. 取得フロー
1.  **バリデーション**: `control_key`が空でないことを確認する。
2.  **キャッシュ確認 (任意)**:
    *   パフォーマンス向上のため、既にメモリ上にキャッシュされている場合はその値を返す。
3.  **DB検索**:
    *   以下のSQL（またはORM equivalent）を実行する：
        ```sql
        SELECT CONTROL_VALUE 
        FROM M_SYSTEM_CONTROL 
        WHERE CONTROL_KEY = :control_key 
          AND SECTION = ISNULL(:section, 'COMMON');
        ```
4.  **結果判定**:
    *   データが存在する場合：`CONTROL_VALUE`を返す。
    *   データが存在しない場合：
        *   ログに警告を出力し、nullまたは定義されたデフォルト値を返す。

## 6. 例外処理
*   DB接続エラー時は `Internal Server Error` をスローし、共通エラーハンドラで処理する。
*   取得値の型変換（Booleanへの変換など）に失敗した場合は、安全なデフォルト値を採用する。
